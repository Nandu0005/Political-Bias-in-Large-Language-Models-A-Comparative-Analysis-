# Political Bias Analysis in Large Language Models

## A Comparative Analysis of ChatGPT-4, Perplexity, Google Gemini, and Claude

### Based on IEEE Access Paper (January 2025)

---

## 📋 Project Overview

This project implements a comprehensive framework for detecting, measuring, and comparing political bias across four major Large Language Models:

- **ChatGPT-4** (OpenAI)
- **Claude** (Anthropic)
- **Google Gemini**
- **Perplexity AI**

The implementation follows the methodology from the research paper, using three standardized political questionnaires and quantitative bias scoring.

---

## 🎯 Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Model Analysis** | Direct comparison of 4 leading LLMs |
| **Standardized Questionnaires** | Pew Research (20 Q), Political Compass (62 Q), ISideWith (158 Q) |
| **Quantitative Bias Scoring** | Combines keyword, embedding, and sentiment analysis |
| **Statistical Rigor** | t-tests, p-values, confidence intervals, effect sizes |
| **Paper Figures** | Generates all 7 figures from the paper (Figures 7-13) |
